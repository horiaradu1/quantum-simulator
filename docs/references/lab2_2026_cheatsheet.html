Numpy Comparisons

np.array_equal(a, b) - Check if two arrays are exactly equal

np.isclose(a, b) - Element-wise comparison with tolerance

np.allclose(a, b) - Check if all elements are close within tolerance

Use approximate comparisons for floating-point results. np.allclose does not ignore global phase.

Matrix Operations

np.transpose(mat) - Transpose of matrix

np.conj(mat) - Conjugate of matrix

mat.conj().T - Conjugate transpose (adjoint) of a 2-dimensional matrix

np.sum([mat1, mat2], axis=0) - Sum of two matrices

np.dot(a, b) - Dot product of two arrays or matrices; it does not conjugate complex inputs

A @ B - Matrix product; A * B is element-wise multiplication

np.vdot(a, b) - Inner product of vectors, conjugating the first argument

k=5; a=np.array([1,2,3]); prod = k*a - Multiply array with a constant

np.linalg.det(mat) - Determinant of matrix

np.linalg.matrix_rank(mat) - Rank of matrix

np.linalg.norm(a) - Euclidean norm of a vector

values, vectors = np.linalg.eig(mat) - Eigenvalues and eigenvectors; column vectors[:, i] corresponds to values[i]

Eigenvalues need not be sorted; eigenvectors are not unique in scale or phase.

Transposing a 1-dimensional array leaves its shape unchanged. States must be normalized; gates must be square and unitary. A sum of gates need not be unitary.

Gate Application and Order

U @ state - Apply a gate to an amplitude array

B @ A @ state - Apply A first, then B; the rightmost matrix acts first

In this lab, multiply_gates([A, B, C]) returns A @ B @ C, not the chronological sequence A, B, C.

A unitary gate's inverse is its adjoint, not generally its transpose.

Tensor Products and Qubit Ordering

np.kron(a, b) - Tensor product; the left factor comes first in lab basis labels

An n-qubit state has 2**n amplitudes. A full n-qubit gate matrix has shape (2**n, 2**n).

Lab order: q0 q1 ... q(n-1); q0 is the most significant bit. For three qubits, index 5 is |101>.

int("101", 2) - Convert a basis bitstring to its array index

format(index, f"0{n}b") - Convert an index to an n-bit basis label

np.eye(2**k, dtype=complex) - Identity on k qubits; k = 0 gives a 1 x 1 matrix

State.apply_gate(gate, n_gate, starting_qubit) acts on a consecutive block. Surround the gate with identity tensor factors for unaffected qubits.

CNOT uses the block's first qubit as control; CNOT10 reverses control and target.

Random Operations

np.random.choice(a) - Random sample from 1-D array

np.random.choice([0,1], p=[0.2, 0.8]) - Random sample from either 0 or 1, with probabilities 0.2 for 0 and 0.8 for 1

np.random.seed(2026) - Make the trials above reproducible

rng = np.random.default_rng(2026) - Independent generator; sample with rng.choice(...)

Probabilities must be nonnegative and sum to 1. Drawing an outcome does not update a state array.

Sampling versus Collapsing Measurement

State.sample() - Draw an outcome without changing the state; repeated calls represent independent preparations.

State.produce_measurement() - Draw an outcome and collapse the stored state.

measure_computational(state) and measure_plus_minus(state) update the input in place. Use writable floating-point/complex arrays, not integer arrays.

A +/- collapse stores the computational-basis amplitudes of |+> or |->.

Repeated collapse in the same basis returns the same outcome. For independent shots, copy the original state for each trial or use sample().

State Representations

np.abs(state) - Magnitudes of the complex amplitudes

np.abs(state)**2 - Computational-basis measurement probabilities

np.real(state), np.imag(state) - Components for complex-amplitude plots

One qubit: |ψ⟩ = eiω(cos(θ/2)|0⟩ + eiφsin(θ/2)|1⟩). Theta ∈ [0, π]; phi is relative phase; omega is global phase.

At the poles, phi is undetermined: follow the notebook's convention. Phases are modulo 2π.

A pure-state Bloch sphere represents one qubit, not a general entangled register.

Qiskit: Local Circuit Simulation

If not using the included requirements file:

from qiskit import QuantumCircuit, transpile
from qiskit.quantum_info import Statevector
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

qc = QuantumCircuit(3)
qc.x(0)  # Syntax example, not the assigned circuit.
print(qc.draw(output="text"))

qc.h(q), qc.s(q), qc.cx(control, target), qc.ch(control, target), qc.swap(q1, q2), qc.ccx(control1, control2, target) - Gate methods

Obtain exact amplitudes before adding measurements:

sv = Statevector.from_instruction(qc)
amplitudes_lab_order = sv.reverse_qargs().data

To collect sampled counts, measure a copy of the circuit:

measured_qc = qc.copy()
measured_qc.measure_all()
simulator = AerSimulator()
compiled = transpile(measured_qc, simulator)
counts = simulator.run(compiled, shots=1024,
                       seed_simulator=2026).result().get_counts()
counts_lab_order = {bits[::-1]: count for bits, count in counts.items()}
plot_histogram(counts_lab_order)

Qiskit draws q0 at the top but labels states q(n-1) ... q1 q0. Reverse the reported order above to match the lab; keep wire numbers unchanged.

The count reversal assumes one classical register with q[i] measured into c[i], as in this example. Other mappings require different conversions.

Statevector(a).equiv(Statevector(b)) - Compare up to global phase; first use the same qubit order
